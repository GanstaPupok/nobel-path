# 🎓 Путь к Нобелевке

Браузерная текстовая life-sim игра. Проживи жизнь учёного — от школьной парты
до Нобелевской премии: школа, вуз, аспирантура, лаборатория, интриги, семья.

Без сборки и зависимостей: чистые ES-модули + CSS. Работает на телефоне.
Можно играть за героя или героиню — тексты согласуются с выбранным полом.

---

## Как запустить

Игру **нельзя** открыть двойным кликом по `index.html` — браузеры блокируют
ES-модули по протоколу `file://`. Нужен любой локальный сервер:

```bash
# вариант 1: встроенный сервер (нужен Node 22+)
npm start            # → http://127.0.0.1:8080

# вариант 2: Python
python -m http.server 8080

# вариант 3: просто задеплойте папку на GitHub Pages / Netlify / Vercel
```

## Как играть

- **Энергия** — 3 действия в год (+1 за здоровье >70, +1 за харизму >70).
  «Завершить год» пропускает остаток энергии.
- **Действия разложены по вкладкам** — 🔬 Наука, 🏛️ Карьера, 🌿 Жизнь.
  На вкладке видно, сколько там доступно действий.
- **Этапы:** детство → вуз → аспирантура → карьера. Текущая цель всегда
  написана под именем героя.
- **Научный проект** — главная долгая цель. В вузе ты выбираешь специализацию
  и получаешь тему (квантовые вычисления / геном / ИИ). Тема проходит
  три этапа; каждый закрытый этап — открытие, репутация и деньги.
  Прогресс даёт действие «Работать над проектом» (стоит денег на реактивы),
  эксперименты, конференции и события-прорывы.
- **Вехи жизни** — 12 ключевых моментов (выпускной, тема диссертации, кризис
  середины пути, юбилей…). Это не рядовые события, а решения с последствиями.
- **Карьерная ветка** — в 30 лет выбираешь, кем быть: исследователем,
  управленцем, преподавателем или прикладником. Ветка меняет бонусы и то,
  каким получится финал.
- **Журналы.** Статью можно отправить в сборник конференции (быстро и без
  риска), в обычный журнал или в топовый — там репутация выше, но рецензенты
  могут завернуть. Топовые статьи дают деньги и очки навыков.
- **Династия.** В финале, если у героя есть ребёнок, можно продолжить игру
  за него: другое имя, другой пол, но наследство родителя — интеллект,
  харизма, деньги и репутация. Поколения считаются.
- **Люди рядом** — четыре большие сюжетные линии: любовь, семья, соперник и
  наставник. У каждой 5–6 стадий, свой выбор и свой финал.
- **Стресс** выше 80 бьёт по здоровью, на 100 — выгорание и потеря года.
  При нулевом здоровье врачи спасают один раз за жизнь.
- **Публикации** дают всё меньше репутации: каждая следующая статья ценится
  ниже, так что «фармить» их бессмысленно.
- **Наследие (🌀 ОН)** — мета-прогрессия: очки за каждую жизнь тратятся на
  постоянные бонусы, которые работают во всех следующих жизнях.
- **Дерево навыков** (🌳) — очки за публикации, открытия и повышения.
- **Достижения** (🏅) — 45 штук.
- **Хроника жизни** (📜) — летопись ключевых моментов по возрастам: свадьба,
  открытия, повышения, вехи. Журнал показывает последние строки, а хроника
  помнит всю жизнь.
- **Эпилог** — в финале игра рассказывает, чем закончилась жизнь: карьера,
  тема, семья, дети, соперник, наставник и реплика под конкретную концовку.

### Люди рядом

Отношения — не декорация: они дают пассивные бонусы, открывают действия
и влияют на финальный титул.

- **💞 Любовь.** В 20–32 ты выбираешь партнёра: художница (снимает стресс),
  учёный (подтягивает интеллект) или предприниматель (приносит деньги).
  Дальше — быт, свадьба, медовый месяц, кризис в 42 и возможность развода.
  Чувства медленно остывают: их поддерживает действие «Время с партнёром».
- **👶 Семья.** Ребёнок рождается, идёт в школу, находит талант, бунтует
  подростком и выбирает путь. Связь с ребёнком растёт от «Времени с ребёнком»
  и решений; крепкая связь даёт здоровье, а учёба и секции стоят денег.
- **⚔️ Соперник.** Виктор появляется в аспирантуре: крадёт идеи, портит
  эксперименты, вызывает на публичную дуэль. Можно победить, проиграть или
  помириться — и встретиться снова через двадцать лет.
- **🎓 Наставник.** Профессор берёт тебя в группу, просит писать за него,
  продвигает твою работу, болеет — и оставляет тебе свою лабораторию.

### Финалы

- 🥇 **Нобель** — репутация 95, интеллект 95, 7 открытий, 12 публикаций
  и полностью закрытый научный проект;
- 🏛️ **директор НИИ** — дошёл до вершины карьерной лестницы;
- 🌍 **всемирно известный учёный** — 8 публикаций, репутация 75, 2 открытия;
- 💼 **бизнесмен от науки** — 5 000 000 ₽;
- 🧑‍🏫 **хороший преподаватель** — крепкая карьера без прорывов;
- 😞 **бездарь**, 🔥 **выгорание**, 💔 **здоровье не выдержало**.

Титул в финале зависит от прожитого: «Семейный профессор», «Одинокий гений»,
«Патриарх науки», «Победитель соперника», «Учёный, отдавший всё науке» —
и это только часть вариантов.

## Разработка

```bash
npm start           # локальный сервер
npm test            # 60 симулированных жизней: падения, NaN, баланс
npm run sim         # 200 жизней на каждую стратегию, подробный отчёт
npm run test:e2e    # 29 проверок в реальном браузере (Chrome/Edge) через CDP
```

`tools/simulate.mjs` — headless-симулятор: прогоняет жизни без браузера,
ловит исключения и NaN, считает распределение финалов, число событий
и вех, долю завершённых проектов. Отдельно проверяет сохранение
с перезагрузками — самый частый источник падений.

`tools/e2e.mjs` — проверки в настоящем браузере: старт, наследие, дерево
навыков, достижения, веха жизни, карточка проекта, вкладки, карточки арок,
действия с партнёром, финал, перезагрузка, консольные ошибки.

### Структура

```
index.html
manifest.webmanifest · sw.js · icons/   (PWA: установка и офлайн)
styles/        themes.css · main.css · minigames.css
js/
  config.js        константы: навыки, предыстории, проекты, зарплаты, пороги
  state.js         состояние, сохранение, миграции
  actions.js       действия по этапам и вкладкам
  year.js          конец года: расходы, стресс, переходы этапов, события
  project.js       научный проект: этапы, прогресс, награды
  publishing.js    публикации: выбор журнала и риск отказа
  chronicle.js     хроника жизни (летопись ключевых моментов)
  epilogue.js      эпилог для финального экрана
  arcs.js          арки отношений: прогресс, карточки, сводка для финала
  finals.js        финалы и начисление наследия
  events/          движок + пулы событий (общие, этапы, дилеммы, арки,
                   редкие, предыстории) и вехи жизни
  ui/              экраны: старт, игра, события, модалки, финал
  minigames/       тест, пазл, защита диссертации, «найди ошибку»
  tree.js          жизненные выборы и их отложенные последствия
  quests.js        квесты (шаблоны + прогресс)
  achievements.js  достижения и очки навыков за вехи
```

### Текст и род героя

Все реплики написаны в мужском роде и на лету превращаются в женский, если
игрок выбрал «Девочка». За это отвечает `js/text.js`:

- меняются только глаголы, где подлежащее — герой: после «Ты …» и в начале
  фразы («Учился в школе.» → «Училась в школе.»);
- есть словарь неправильных форм (`ушёл → ушла`, `смог → смогла`,
  `достиг → достигла`) и правило для возвратных (`родился → родилась`);
- существительные на «-л» (`провал`, `титул`, `скандал`) не трогаются;
- названия достижений, концовок и предысторий подобраны нейтрально.

Новый текст достаточно писать в мужском роде — женская форма образуется сама.

### Важное правило про сохранения

Состояние лежит в `localStorage` под ключом `nobel_path_v6`, наследие — под
`nobel_path_legacy`. **В состоянии не должно быть функций**: JSON их теряет, и
после перезагрузки игра падала на `q.check is not a function`.

Поэтому:
- квесты хранятся как `{id, startAge, startValue, deadlineAge}`, а логика
  подтягивается из `QUEST_POOL` по `id`;
- `pendingEvent` и `pendingModal` при записи обнуляются;
- `state.js → migrate()` чинит старые и битые сохранения (NaN, мусор,
  отсутствующие поля) и никогда не бросает исключение.

## Баланс

По данным симулятора (`npm run sim`):

| Стратегия | Нобель | Известный | Преподаватель | Смерть |
|---|---|---|---|---|
| осмысленная игра | ~43% | ~38% | ~18% | ~1% |
| случайные кнопки | 0% | ~28% | ~70% | ~2% |

Вуз проходят 100% осмысленных игроков, аспирантуру — ~85%,
научный проект до конца доводят ~80%. Брак складывается у ~55%,
наследие семьи — у ~37%, наставник оставляет лабораторию ~75% игроков.
